Format: JSON

Category: Specify whether the entity is a business company, business name, or company.

Fields:

id
company_name
registration_number
category ("business name"/"company")
registered_address
incorporation_date
main_object
share_capital (for company)
proprietors (for business name) or directors (for company)
company_sec (for company) or trustee_sec (for trustee)
shareholders (for company)
Detailed Constraints:

For business names, include proprietors as an array of objects with name and address.
For companies, include directors as an array of objects with name and address as well as shareholders as an array of objects with name and shares. The shares and share_capital should be numeric, formatted with commas (e.g., "1 million" becomes "1,000,000").
If an address is missing, use the company's registered address for the proprietors, directors, or shareholders.
